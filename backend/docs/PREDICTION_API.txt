calibrated=false로 응답합니다. sigmoid를 명시하면 기존 보정기를 사용합니다.

prediction_ready=true, model=xgboost, variant=raw이면 기본 모델이 로드된 상태입니다.
이미 서버가 실행 중이면 변경 사항을 적용하기 위해 재시작하세요.

API:
GET /api/races/{session_key}/battles?ready_only=true&offset=0&limit=100
  예측 시점의 battle_ready만으로 필터링합니다. 미래 라벨/사후 offline_eligible로 조회를 제한하지 않습니다.
POST /api/prediction/overtake
  {"battle_id":"목록의 battle_id", "prediction_time":"목록의 prediction_time 원문"}
  응답: probability, calibrated, variant, model, target, data_role, battle_id, prediction_time
  예측 시각은 마이크로초를 보존해야 하므로 임의로 초/밀리초로 반올림하지 마세요.

모델/경로 변경이 필요할 때 backend 환경변수 또는 .env 설정:
OVERTAKE_MODEL_PATH=원하는 모델 경로
OVERTAKE_MODEL_VARIANT=raw
REPLAY_DATA_DIR=원하는 candidates.parquet 상위 폴더
상대 경로는 backend 기준입니다. 기존 REPLAY_MODEL_PATH는 모델 선택에 사용하지 않습니다. OVERTAKE_MODEL_PATH를 설정하세요.
외부 API 주소는 frontend/.env.local의 NEXT_PUBLIC_API_URL에서 설정합니다.
로컬 기본값은 http://localhost:8000이며 변경 후 프론트 서버를 재시작하세요.

예외 처리:
404: 저장된 경기/배틀/시각 없음
422: 잘못된 입력, 준비되지 않은 배틀, 필수 피처 부족
503: 모델 없음 또는 시작 시 로드 실패 (서버 로그 확인)
500: 예상치 못한 데이터/모델 처리 오류
학습 시 허용된 선택적 피처 결측은 저장 파이프라인의 대치 방법을 그대로 사용합니다.
간격·순위·랩·배틀 지속 시간 같은 필수 피처가 없으면 확률을 만들지 않습니다.

화면:
저장 배틀 패널에서 관측 선택, 이전/다음 관측, 100개 단위 페이지 이동, 자동 재생/일시정지가 가능합니다.
요청 중 경기를 바꾸거나 관측을 옮기면 이전 요청을 취소하고 오래된 확률을 숨깁니다.
자동 재생은 관측 순서대로 진행하며 실제 경기 시간 속도를 재현하지 않습니다.
이 패널의 관측 시각은 기존 지도·텔레메트리 요약과 동기화되지 않습니다.
